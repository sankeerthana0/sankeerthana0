## ⚙️ How I Build

I try to approach projects as **systems rather than isolated models or demos**.

```text
Problem
   ↓
Understand requirements & constraints
   ↓
Design the system
   ↓
Build the core functionality
   ↓
Evaluate & benchmark
   ↓
Optimize performance
   ↓
Deploy
   ↓
Monitor & iterate
````

Depending on the problem, this can involve:

**Data → Processing → Model/LLM → Retrieval → APIs → Infrastructure → Evaluation → Monitoring**

I care about questions such as:

* How does the system behave with real inputs?
* What happens when a component fails?
* Can the system be evaluated objectively?
* Where are the performance bottlenecks?
* How can latency and resource usage be reduced?
* How should the system be monitored after deployment?
* Can the architecture scale as usage grows?

# 🔬 Research & Applied ML

My research experience has focused on problems where traditional supervised learning can struggle because of **limited data, heterogeneous data, or complex relationships between labels**.

### Few-Shot & Zero-Shot Learning

Built an embedding-based classification framework using:

* Prototypical Networks
* Metric learning
* Contrastive loss
* Triplet loss
* Support/query evaluation

The work focused on understanding **embedding quality and generalization under limited training data**.

### Medical Image Classification

Built a multi-label medical image classification pipeline and benchmarked multiple CNN architectures:

`ResNet18` • `ResNet50` • `EfficientNet` • `DenseNet` • `ConvNeXt-Tiny` • `SqueezeNet`

Also explored a **Graph Convolutional Network** for modeling label relationships and evaluated models using:

`ROC` • `Precision-Recall` • `F1` • `Kappa`
